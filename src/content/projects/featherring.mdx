## The problem

An agent that can only read text is blind to most of what a computer actually
holds. One that can read everything runs out of context immediately.

## The approach

Treat context as a managed resource rather than a buffer: extract entities
agentically, summarise selectively, and retrieve from memory on demand, so the
working set stays small while the addressable set does not.
