EvalRing answers one question: out of all these options, which one is actually best at my task? It is published on PyPI as `evalring` and works offline for a first run.

## The problem

You have a job for a language model: sort support tickets, pull dates out of contracts, judge whether an answer is any good. There are many ways to build it and no obvious way to tell which wins. So you write a quick script, then another when someone asks whether a cheaper model would do. The prompt changes and nobody can say whether the score moved because the wording is better or because the test examples were different. A month later nobody knows how the number in the slide was produced.

## The approach

Most evaluation tools score one model on a standard benchmark. EvalRing turns that around: the task is fixed, and what varies is the candidate. If you can call it from Python, it can be in the comparison. Each run saves the per-example results and the exact settings next to the scores, so a number stays explainable six months later.

```bash
pip install "evalring[llm]"
```
