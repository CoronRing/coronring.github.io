## The problem

A single agent loop degrades in predictable ways: it fills its context with
material it read once and will never use again, and it grades its own work.
Both failure modes are structural rather than a prompting issue.

## The approach

Decompose the task into independent units, run each in its own context, and
verify findings with agents that never saw the reasoning that produced them.
