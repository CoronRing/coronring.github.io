## What it is

A set of tools that accumulated around real work: request builders for model
APIs, text and directory diffing, extraction pipelines, and small GUIs that
make each of them usable without remembering a command-line invocation.

## Why it exists

Every one of these started as a script written to solve exactly one problem.
The ones that got reused earned a place here.
